# Excel-Project
The primary goal of this project is to analyze sales data from a superstore to improve inventory management and optimize sales performance. By leveraging Excel, I aim to provide actionable insights that will help in making informed decisions regarding stock levels, order processing, and customer satisfaction.

## Dataset used
<a href="https://github.com/duval-ys/Excel-Dashboard-Project/blob/main/RAW%20DATA.csv">dataset</a>

## KPI questions
	Which customer segments are contributing the most to overall sales?


	Which regions are showing the highest sales growth?


	Are there any regions with declining sales trends?
